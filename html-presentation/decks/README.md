## باز کردن
1. فایل `index.html` پوشهٔ ارائه را با Chrome یا Edge باز کنید (دو بار کلیک، یا کشیدن فایل روی پنجرهٔ مرورگر).
2. کلید `F` را بزنید تا تمام‌صفحه شود.
3. پیش از جلسه یک بار روی همان سیستم و نمایشگر پخش، از اول تا آخر جلو بروید.

## ارائه با کلیکر
| کلید | کار |
|---|---|
| کلیکر، `→`، `↓`، `PageDown`، `Space`، کلیک روی صفحه | گام بعدی |
| `←`، `↑`، `PageUp`، `Backspace` | گام قبلی |
| `O` | فهرست اسلایدها؛ با کلیک به هر اسلاید بروید |
| شمارهٔ اسلاید (مثلاً `1` سپس `2`)، `Home`، `End` | پرش به اسلاید |
| `B` یا `.` | صفحهٔ سیاه |
| `T` | زمان‌سنج (`Shift+T` صفر می‌کند) |
| `F` | تمام‌صفحه |
| `D` | برعکس‌کردن جهت فلش‌ها، اگر کلیکر برعکس کار کرد |
| `?` | راهنمای میانبرها |
| `Esc` | بستن راهنما، فهرست یا صفحهٔ سیاه |

میانبرها با صفحه‌کلید فارسی و اعداد فارسی هم کار می‌کنند.
