# نمونهٔ ارائهٔ تعاملی: از ERP که ثبت می‌کند، تا ERP که اقدام می‌کند

نمونهٔ ۵ اسلایدی از ارائهٔ «سفر به سازمان‌های هوشمند»، به‌صورت یک فایل HTML مستقل، بدون نیاز به نصب یا build.

## باز کردن
فایل `index.html` را دو بار کلیک کنید تا در مرورگر (ترجیحاً Chrome یا Edge) باز شود، سپس کلید `F` را برای تمام‌صفحه بزنید.
بدون اینترنت هم کار می‌کند؛ فقط فونت Vazirmatn از Google Fonts می‌آید و اگر فونت SG Kara روی سیستم نصب باشد، همان استفاده می‌شود. لوگو داخل خود فایل است.

## ارائه با کلیکر
هر اسلاید چند «گام» دارد. هر کلیک فقط بخش بعدی همان اسلاید را نشان می‌دهد و در پایان اسلاید، به اسلاید بعد می‌رود. برای همین ارائه‌دهنده می‌تواند روی هر بخش به اندازهٔ لازم توضیح دهد. خط‌های کوچک پایین صفحه نشان می‌دهند در کدام گام هستید.

| کلید | کار |
|---|---|
| کلیکر، `→`، `↓`، `PageDown`، `Space`، کلیک روی صفحه | گام بعدی |
| `←`، `↑`، `PageUp`، `Backspace` | گام قبلی (از اول اسلاید به آخرین گام اسلاید قبل) |
| `1` تا `5`، `Home`، `End` | پرش به اسلاید |
| `B` یا `.` | صفحهٔ سیاه |
| `T` | نمایش زمان‌سنج (`Shift+T` صفر می‌کند) |
| `F` | تمام‌صفحه |
| `D` | برعکس‌کردن جهت فلش‌ها (اگر کلیکر برعکس عمل کرد) |
| `?` | راهنمای میانبرها |

کلیک روی هر عنصر (پلهٔ نردبان، Agent، سطح ریسک و…) مستقیم به همان گام می‌رود. دکمه‌ها و نشانگر ماوس پس از چند ثانیه بی‌حرکتی پنهان می‌شوند.

## اسلایدها و گام‌ها
1. **جلد**: عنوان ← تبدیل «ثبت‌کردن» به «اقدام‌کردن» ← معرفی ارائه‌دهنده و لوگو
2. **ERP برای پاسخگویی به آرزوی مشتریان**: System of Record ← Intelligence ← Action ← جمع‌بندی
3. **AI از پاسخ دادن به انجام دادن**: Search ← Assistant ← Copilot ← AI Agent ← چهار مرحلهٔ کار Agent (تحلیل، تصمیم، ثبت سفارش خرید، پایش)
4. **Agentها همکاران دیجیتال‌اند**: شش Agent یکی‌یکی ← جمع‌بندی و چرخهٔ Goal → Learn & Monitor
5. **AI بدون Governance خطرناک است**: سه رکن ← سه سطح ریسک ← سه سناریوی نمونه (و انتخاب آزاد سناریو) ← جمع‌بندی

## افزودن اسلاید جدید
- **متن‌ها**: در بلوک `<script type="application/json" id="slide-data">`.
- **ساختار**: یک `<section class="slide" id="s-...">` به `#stage` اضافه کنید. عناصری که `data-r` دارند هنگام ورود به اسلاید ظاهر می‌شوند و عناصر `sx` با گام‌ها.
- **رفتار**: در اسکریپت بنویسید `defineSlide('s-...', S => ({ steps: N, show(n){ … } }))`. تابع `show(n)` وضعیت اسلاید را برای گام `n` می‌سازد، پس جلو و عقب رفتن خودکار درست کار می‌کند.
- ترتیب اسلایدها همان ترتیب `<section>`ها در فایل است.

> سناریوهای اسلاید ۵ و چند برچسب کوتاه (مانند «زنجیرهٔ همکاری») نمونه‌اند و باید با محتوای نهایی تطبیق داده شوند.
